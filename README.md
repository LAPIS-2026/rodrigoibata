# Códigos para Práctico — Prof. Rodrigo Ibata (LAPIS 2026)

Repositorio de materiales y códigos para el práctico del Profesor Rodrigo Ibata (*High-precision Machine Learning for Next-Generation Galactic Archeology*) en la escuela de astrofísica **XII LAPIS 2026**.

## Proyectos y Plataforma

- **Datos y software**: Los datos y el software estarán disponibles a través de **Google Colab**.
- **Proyectos propuestos**:
  1. **AI-Kepler**: Redescubrimiento automático de las leyes del movimiento planetario a partir de datos usando regresión simbólica acoplada a un optimizador de segundo orden.
  2. **LeMondeModèle**: Espacios latentes de redes neuronales con codificación física interpretable.
  3. **Symplectomania**: Construcción de un flujo hamiltoniano para un sistema dinámico simple.
